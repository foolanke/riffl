# Font sources

All fonts are self-hosted so the app never loads fonts from the internet at runtime (SPEC 0.2 offline rule).
Downloaded once on 2026-11-21.

## SpaceGrotesk-Medium.woff2

- CSS: `font-family: 'Space Grotesk'; font-weight: 500; font-style: normal;`
- Static Medium (500) instance, Google Fonts "latin" subset
  (unicode-range U+0000-00FF, U+0131, U+0152-0153, U+02BB-02BC, U+02C6, U+02DA, U+02DC, U+0304, U+0308, U+0329, U+2000-206F, U+20AC, U+2122, U+2191, U+2193, U+2212, U+2215, U+FEFF, U+FFFD).
- Found via: `https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@500&display=block`
- File URL: `https://fonts.gstatic.com/s/spacegrotesk/v22/V8mQoQDjQSkFtoMM3T6r8E7mF71Q-gOoraIAEj7aUXskPMA.woff2`
- Licence: SIL Open Font License 1.1, see `SpaceGrotesk-OFL.txt`
  (from `https://raw.githubusercontent.com/floriankarsten/space-grotesk/master/OFL.txt`).

## ClashDisplay-Semibold.woff2

- CSS: `font-family: 'Clash Display'; font-weight: 600; font-style: normal;`
- Static Semibold (600) file served by the Fontshare CSS API.
- Found via: `https://api.fontshare.com/v2/css?f[]=clash-display@600&display=block`
- File URL: `https://cdn.fontshare.com/wf/FPDAZ2S6SW4QMSRIIKNNGTPM6VIXYMKO/5HNPQ453FRLIQWV2FNOBUU3FKTDZQVSG/Z3MGHFHX6DCTLQ55LJYRJ5MDCZPMFZU6.woff2`
- Licence: ITF Free Font License (FFL) v2.0, Indian Type Foundry / Fontshare, see `ClashDisplay-LICENSE.txt`
  (the `License/FFL.txt` file from the official download zip `https://api.fontshare.com/v2/fonts/download/clash-display`).
- Note: the FFL allows free personal and commercial use and self-hosting for your own site/app,

  Check this before committing the file to a public Git repository.
